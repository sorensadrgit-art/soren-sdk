# SDK Specialist Skill Template

## What this skill owns

Define the exact capabilities and ownership domains.

## Activate this skill when

List concrete task signals and project conditions.

## Do not activate this skill when

List native alternatives, simpler options, conflicts, and unsupported environments.

## Required inspection

List files, versions, dependencies, policies, and ownership declarations to inspect.

## Setup

Define target workspace, packages, imports, protocol versions, configuration, and credentials by name.

## Lifecycle and cleanup

Define initialization, teardown, hot reload, route changes, and duplicate protection.

## Accessibility

Define keyboard, focus, reduced motion, semantics, and fallback behavior.

## Performance

Define bundle, loading, rendering, observer, and main-thread requirements.

## Security and permissions

Define filesystem, network, command, tool, data-exposure, and consent requirements.

## Compatibility and ownership

Define compatible providers, scoped ownership, adapters, and hard conflicts.

## Approved recipes

Reference focused files in `recipes/` or `references/`.

## Required verification

List hard gates and quality checks.

## Common mistakes

List incorrect patterns and fixes.

## Evidence requirements

List connector-specific facts that must appear in the evidence envelope.
