# License Policy

## Current repository status

As of 2026-07-27, this repository does not contain a root `LICENSE` file.

Public visibility does not automatically grant permission to copy, modify, distribute, or commercially reuse the repository.

Do not add a license on behalf of the owner without explicit approval.

## Connector license requirements

Before a connector becomes selectable, record:

- Runtime package license using an SPDX expression
- Skill and documentation license or terms
- MCP server terms when applicable
- Commercial or paid-plan restrictions
- Redistribution constraints
- Whether examples may be stored, summarized, or only linked

`NOASSERTION` or an unresolved license must block approval for normal routing.

## Future repository license decision

The owner should choose one of these directions before accepting outside contributions or publishing packages:

- Open-source license
- Source-available license
- Proprietary license
- Mixed licensing by package or directory

The decision must be recorded in an ADR and reflected in:

- Root `LICENSE`
- Package manifests
- Connector content
- Contribution policy
- Published artifacts
